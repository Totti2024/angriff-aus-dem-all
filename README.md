# Angriff aus dem All

Retro-Space-Shooter von Totti Games, gebaut fürs iPhone im Hochformat (läuft auch auf Mac und iPad).

- Spielen: https://totti2024.github.io/angriff-aus-dem-all/
- iPhone: in Safari öffnen, Teilen, «Zum Home-Bildschirm». Danach Vollbild und offline.

Steuerung: Finger ziehen (Schiff schiesst selbst). Mac: Pfeile oder Maus ziehen, Leertaste startet, P pausiert, M schaltet den Ton.

Eine Datei (`index.html`), keine Abhängigkeiten. `sw.js` hält das Spiel offline bereit; bei Änderungen `CACHE` in `sw.js` hochzählen.
